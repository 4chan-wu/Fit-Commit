앱에서 바로 처리 연결 데이터 함께 삭제
01

앱에서 바로 삭제하기

  1. Fitcommit 앱에 로그인합니다.
  2. 하단 메뉴에서 마이를 선택합니다.
  3. 계정 삭제를 누르고 안내 내용을 확인합니다.
  4. 삭제를 확정하면 계정과 연결 데이터가 제거됩니다.
02

삭제되는 데이터

  • Supabase Auth 로그인 계정과 프로필
  • 생성한 옷장과 등록한 의류 정보
  • 스토리지에 업로드한 의류 사진
삭제는 되돌릴 수 없습니다.
법령상 별도 보존 의무가 없는 한 삭제된 정보는 복구하거나 별도로 보관하지 않습니다.
03

앱에 접근할 수 없는 경우

Fitcommit 지원 요청을 생성해 삭제 요청 방법을 문의하세요. 공개 요청에는 이메일 전체, 비밀번호 또는 사진을 작성하지 마세요. 계정 소유 확인은 공개되지 않는 별도 절차로 진행해야 합니다.
